# Security Policy

## Policy

This page is part of the Acme engineering handbook. It documents how the team works, why the system is built the way it is, and what to do when something goes wrong. Keep it current: when behavior changes, update the page in the same change, because stale docs cost more than missing ones. Every section below is written to be read on its own.

## Practice

Least privilege by default. Access is granted through review and expires automatically.

## Audit

Every access decision is logged and reviewed on a schedule.
